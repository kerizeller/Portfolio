# Keri Zeller – Portfolio website

A static site for GitHub Pages. No build step: upload these files as they are.

## Publish on GitHub Pages
1. Create a new **public** repository (for example `portfolio`).
2. Upload everything in this folder, keeping the `css`, `images`, and `files` folders.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose **main** and **/ (root)**, and save.
4. Your site appears at the address GitHub shows on that page within a few minutes.
5. Custom domain (kerizeller.com): add it under Settings → Pages only after the Namecheap transfer finishes and the DNS records are set.

## What's inside
- `index.html` – home page; one page per project; `cv.html`
- `files/Keri_Zeller_CV.pdf` – web version of the CV (phone number left off for privacy)
- `files/samples/` – work samples linked from the project pages
- `images/keri.jpg` – portrait

## Updating
Edit the text in any `.html` file directly on GitHub (pencil icon) and commit. Replace `files/Keri_Zeller_CV.pdf` whenever the CV changes.
